# =====================================================================
# requirements.txt  —  the Python libraries the backend needs
# =====================================================================
# Install all of them at once with:
#     pip install -r requirements.txt
#
# fastapi           -> the web framework: lets us create API endpoints
#                      like GET /products and POST /tryon with very
#                      little code.
# uvicorn           -> the web server that actually runs the FastAPI app
#                      and listens on http://127.0.0.1:8000
# python-multipart  -> lets FastAPI read uploaded files (the user's photo)
#                      sent as "multipart/form-data".
# httpx             -> makes HTTP requests from Python. We use it to call
#                      the Genlook virtual try-on API.
# python-dotenv     -> reads the secret values (API key) from the .env file.
# cloudinary        -> official Cloudinary library: uploads garment images
#                      to the cloud and gives back a public https link.
# gradio_client     -> calls free AI demos ("Spaces") on Hugging Face. We use
#                      it for the 3D model feature (Hunyuan3D-2.1).
# pillow            -> opens and resizes images in Python (we shrink the
#                      image before sending it for 3D generation).
#
# TODO: If you add a new library later, add it here so that other
#       people (and your future self) can install it too.
